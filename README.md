# AI 비즈니스·디지털서비스 프로젝트 교재 실습 자료

교재의 프로젝트 1~8에서 쓰는 입력 자료, 완성 예제, 실행 도구를 모아 둔 저장소입니다.

## 내려받기

가장 쉬운 방법은 오른쪽의 **Releases**에서 최신 버전을 열고 압축 파일 2개를 내려받는 것입니다.

- `P1-P4_기초실습자료.zip`: 프로젝트 1~4(3~6장)
- `P5-P8_심화실습자료.zip`: 9장과 프로젝트 5~8(10~13장)

저장소 전체를 받으려면 위쪽의 **Code** → **Download ZIP**을 누릅니다. 이 경우 두 자료가 아래 폴더로 함께 들어 있습니다.

| 폴더 | 내용 | 먼저 읽을 파일 |
|---|---|---|
| `P1-P4_기초실습자료/` | `data`(입력 자료), `completed`(검증 결과와 완성 예제), `manifest.json`(파일 목록과 SHA-256) | `실습자료_읽어주세요.txt` |
| `P5-P8_심화실습자료/advanced/` | `input`, `workflows`(Dify 파일·코드), `completed`, `exercises`, `tools`, `map`, `prompts` | `README.txt` |

압축을 푼 뒤에는 인터넷 연결 없이도 저장된 자료로 실습할 수 있습니다. 새로 API를 조회하거나 Dify·생성형 AI를 쓰는 활동만 인터넷이 필요합니다.

## 사용할 때 지킬 것

- 거래·매출·설문·영수증·문의·리뷰 등은 교재용 **가상 데이터**입니다. 실제 학교·매장·개인의 기록이 아닙니다.
- 환율·공시·관광·경로 응답과 법령 조문은 표시된 조회 시점에 저장한 공개 자료입니다. 새로 쓸 때는 각 출처에서 현재 내용을 다시 확인합니다.
- API 키는 `.env.example`을 `.env`로 복사해 자기 컴퓨터에서만 넣습니다. 키가 들어 있는 `.env`는 올리거나 제출하지 않습니다.
- 원본 파일은 그대로 두고 사본에서 작업합니다. 완성 예제는 비교용이며 그대로 자신의 과제로 제출하지 않습니다.
- 사용 방법과 파일 연결은 교재 부록 A(기초)와 부록 E(심화)를 따릅니다.
