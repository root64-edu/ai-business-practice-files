# AI 비즈니스·디지털서비스 프로젝트 — 교재 실습 자료

교재 「AI 비즈니스·디지털서비스 프로젝트」에서 사용하는 입력 자료, 완성 예제와 실행 도구입니다. 기초 프로젝트 1~4와 심화 프로젝트 5~8의 자료를 제공합니다.

## 실습 자료 내려받기

[릴리스 페이지](https://github.com/root64-edu/ai-business-practice-files/releases)에서 최신 버전을 열고, 실습할 범위에 맞는 압축 파일을 내려받으세요.

| 압축 파일 | 교재 범위 | 압축을 푼 뒤 먼저 읽을 파일 |
|---|---|---|
| `P1-P4_basic_practice.zip` | 기초 프로젝트 1~4(3~6장) | `실습자료_읽어주세요.txt` |
| `P5-P8_advanced_practice.zip` | 9장과 심화 프로젝트 5~8(10~13장) | `advanced/README.txt` |

압축 파일 이름은 영문이지만, 안에 들어 있는 파일 이름은 교재에 안내된 이름과 같습니다. 압축을 푼 뒤에는 폴더 구조와 파일 이름을 유지하세요.

저장소 전체가 필요하면 페이지 위쪽의 **Code → Download ZIP**을 선택하세요. 두 실습 자료가 다음 폴더에 들어 있습니다.

| 폴더 | 주요 내용 |
|---|---|
| `P1-P4_기초실습자료/` | `data`(입력 자료), `completed`(검증 결과와 완성 예제), `manifest.json`(파일 목록과 SHA-256 해시) |
| `P5-P8_심화실습자료/advanced/` | `input`, `workflows`(Dify 파일과 코드), `completed`, `exercises`, `tools`, `map`, `prompts` |

## 실습 시작하기

1. 내려받은 압축 파일을 풀고 위 표의 안내 파일을 읽으세요.
2. 원본을 보관하고 사본에서 작업하세요.
3. 교재의 해당 장을 따라 실습하세요. 파일 구성과 사용 방법은 부록 A(기초)와 부록 E(심화)에서도 확인할 수 있습니다.

저장된 자료를 열어 보거나 로컬 도구로 계산하는 활동은 필요한 프로그램이 설치되어 있으면 인터넷 없이 진행할 수 있습니다. Google 시트·Dify·생성형 AI 서비스 이용, 새로운 API 조회와 온라인 지도 이용에는 인터넷 연결이 필요합니다.

## 자료 사용 시 유의 사항

- 거래·매출·설문·영수증·문의·리뷰 등은 교재용 **가상 데이터**입니다. 실제 학교·매장·개인의 기록이 아닙니다.
- 환율·공시·관광·경로 응답과 법령 조문은 자료에 표시된 시점의 공개 자료입니다. 현재 상황에 적용하려면 각 출처에서 최신 내용을 확인하세요.
- API 키가 필요한 활동에서는 `.env.example`을 `.env`로 복사한 뒤 자신의 컴퓨터에서 키를 입력하세요. 키가 들어 있는 `.env`는 업로드하거나 제출하지 마세요.
- 완성 예제는 자신의 결과를 비교하고 점검하는 자료입니다. 그대로 자신의 과제로 제출하지 마세요.
