심화 프로젝트 5~8 실습 자료

1. advanced 폴더를 통째로 풀고 이 파일부터 읽습니다.
2. 저장 자료 계산은 API 키 없이 가능합니다. Python 실행 환경이 필요합니다.
3. advanced에서 터미널을 열고 아래 명령을 실행합니다.
   python tools/run_saved_case.py P6 --input input/P6_통합입력.json --out results/P6_내결과.json
4. P5는 질문(--question), P8은 도구 요청 파일(--action)이 추가로 필요합니다.
   자세한 명령과 파일 연결은 교재 부록 E를 따릅니다.
5. 새 API 조회를 할 때만 .env.example을 .env로 복사해 해당 키를 넣습니다.
   값이 들어 있는 .env는 제출하지 않습니다. 키를 Dify에 저장할 필요가 없습니다.
6. 지도는 KAKAO_JAVASCRIPT_KEY 설정 후 python tools/run_map.py로 실행합니다.
   http://127.0.0.1:8080을 엽니다. REST 키와 JavaScript 키를 구분합니다.
   키가 없으면 지도 서버가 실행되지 않습니다. completed/P8_지도와일정.json의
   plans[].rows와 교재 13장의 B안 지도 그림으로 시간표를 대조합니다.

폴더: input(기준 입력), completed(기준 결과), exercises(조건 변경과 풀이),
workflows(Dify 구성·계산/검색 코드), tools(실행 도구), map(관광 지도).
출력 파일이 있으면 다른 이름을 사용합니다. 원본 입력을 덮어쓰지 않습니다.

Dify: 입문_단위와계산 → 입문_계산과설명 순으로 읽습니다.
P5는 P5_공식자료_근거검색_v3를 사용합니다. 모델 연결은 자신의 작업 공간에서 확인합니다.
P5 기본 흐름은 문자 검색입니다. 내장 문서 임베딩을 실행했다고 전제하지 않습니다.
P8 기본 흐름은 JSON 행동 요청을 검증해 두 번 실행하는 제한된 도구 선택입니다.
로컬 종합 활동이 기본 Dify 앱에 자동 추가되어 있지는 않습니다.

자료 성격: 거래·계획·예약·비율 변화 사례는 가상입니다.
환율·공시·관광·경로 응답은 저장된 조회 시점의 공개자료입니다.
법률 자료의 확인일은 각 조문의 verified_date에 있습니다. 근로기준법 제54조는 2026. 12. 10. 시행 본문입니다.
새 질문은 국가법령정보센터의 현행 원문을 다시 확인합니다.
공식 PDF 전문은 묶음에 넣지 않았습니다. 교재의 공식 게시물에서 원문을 확인합니다.
이 예제는 실제 송금·예약·채용 결정·외부 발송을 수행하지 않습니다.

검토: 계산 결과는 풀이와 대조하고 LLM 문장은 근거·숫자·보류 조건으로 검토합니다.
새 조회나 모델 실행 결과는 시점과 조건에 따라 달라질 수 있습니다.
