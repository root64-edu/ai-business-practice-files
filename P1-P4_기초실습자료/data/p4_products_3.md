# 교재용 가상 상품 사양서와 기존 설명

실제 상품·원재료·제조기록이 아닙니다. 실습에서 사실 대조의 기준으로만 사용합니다. 모든 상품의 배송·교환 안내는 p3_faq_20.md의 가상 정책을 따릅니다.

## 한빛 쿠키 세트
- 가격: 12000
- 구성: 초코칩·헤이즐넛·크랜베리·바닐라·녹차 각 1개, 총 5개
- 규격: 1개 45g, 총 225g
- 원재료: 밀가루, 버터, 설탕, 달걀, 우유, 초콜릿, 헤이즐넛, 크랜베리, 바닐라, 녹차
- 알레르기: 밀, 우유, 달걀, 헤이즐넛 함유. 아몬드 무첨가 보증이나 교차 접촉 안전성은 제공 정보로 확인 불가
- 기간: 교재용 가상 설정: 제조일로부터 7일
- 보관: 서늘하고 건조한 곳에 밀봉 보관
- 제조: 가상 학교 실습실에서 발송 전날 제조. 원재료 원산지는 이 자료에 없으므로 확인 필요
- 포장: 쿠키별 개별 포장 후 종이 상자. 별도 선물 포장 서비스 없음
- 사용: 포장을 열어 섭취. 알레르기 표시 확인
- 기존설명: 한빛 쿠키 세트입니다. 12,000원입니다.
- 사진자료: 미제공. 실제 상품 사진이 아닌 교재용 삽화는 사진 항목 충족으로 세지 않음

## 별빛 노트 세트
- 가격: 8500
- 구성: 서로 다른 표지 디자인 노트 3권
- 규격: A5(148×210mm), 권당 80쪽, 줄 간격 7mm
- 원재료: 내지 종이 80g/m², 종이 표지, 중철 제본
- 알레르기: 해당 없음
- 기간: 해당 없음
- 보관: 습기와 직사광선을 피하여 평평한 곳 보관
- 제조: 가상 학교기업이 디자인하고 가상 국내 인쇄소가 제작
- 포장: 종이 띠로 3권을 묶고 종이 봉투에 포장
- 사용: 연필·볼펜 필기에 사용. 수채화용 종이 아님
- 기존설명: 별빛 노트 세트 3권, A5 크기. 8,500원입니다.
- 사진자료: 미제공

## 교내 포토카드
- 가격: 5000
- 구성: 서로 다른 학교 풍경 사진 10장
- 규격: 장당 55×85mm
- 원재료: 300g/m² 종이, 앞면 유광 코팅
- 알레르기: 해당 없음
- 기간: 해당 없음
- 보관: 물과 열을 피하여 보관
- 제조: 가상 사진 동아리가 기획하고 가상 국내 인쇄소가 제작
- 포장: 투명 보호 봉투와 종이 보강재 사용
- 사용: 감상·수집용. 모니터와 인쇄물의 색은 다를 수 있음
- 기존설명: 학교 풍경을 담은 교내 포토카드 10장입니다. 5,000원입니다.
- 사진자료: 미제공
