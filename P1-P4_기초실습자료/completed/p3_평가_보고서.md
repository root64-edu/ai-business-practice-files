# 문의 응대 챗봇 평가 기록

교재용 가상 문의 40건, FAQ 20개, 평가 질문 30개를 사용했습니다. 문의 유형은 배송 12·교환환불 10·결제 8·재고 6·기타 4건입니다. 일반적인 답을 제시할 수 있는 문의는 37건이며 개인별 카드 거부 사유, 단종 여부, 별도 선물 포장은 담당자 확인 대상으로 남겼습니다.

## 같은 자료로 두 지침 비교

기대 행동을 먼저 고정한 뒤 같은 FAQ 전체와 지침 v1 또는 v2를 제공해 문항별 독립 API 요청을 30건씩 실행했습니다. v1 25/30(83.3%), v2 27/30(90.0%)이 핵심 기대 행동과 일치했습니다. 범위 안 질문은 두 버전 모두 17/18(94.4%)입니다. 문장 수와 세부 말투는 내용 점수와 별도입니다.

v2에서 Q26·Q28의 근거 없는 정책 부정이 개선되었습니다. Q16의 묶음 배송 예외 생성, Q19·Q22의 필수 담당자 안내 누락은 남았습니다. 기존 정답 25건에서 퇴행은 없었습니다. 한 차례의 비교 결과이며 새로운 질문에 같은 성능을 보장하지 않습니다.

Q01을 v2로 별도 3회 실행해 핵심 기간의 일치를 확인했습니다. Q29의 전화번호 접수 거절은 응답 동작 확인이며 서비스의 실제 보관 정책을 감사한 결과가 아닙니다.

## Canvas 앱 확인

5장의 요청문(p3_canvas_request.txt)으로 Gemini Canvas에서 챗봇 앱을 만들고, 관리자 화면에 p3_faq_20.md를 저장한 뒤 평가 질문 일부로 시험했습니다. 작성자가 교재를 준비하며 실행한 예시이며, 같은 요청문을 써도 시점에 따라 결과가 달라질 수 있습니다.

- 지침 v1 앱으로 11문항을 물었을 때 9문항이 기대 행동과 일치했습니다. Q19·Q22는 필수 담당자 안내가 빠졌습니다.
- 앱을 고쳐 새 버전이 만들어진 뒤 저장한 FAQ가 비어 있는 경우가 있었습니다. 이때는 쉬운 질문에도 "이 내용은 제가 확인할 수 없습니다"라고 답하므로, 관리자 화면에서 파일 이름과 글자 수를 확인하고 다시 올린 뒤 시험했습니다.
- 지침을 바꾼 뒤 앱이 실행 오류로 멈춘 경우에는 Canvas의 「오류 수정」을 눌러 복구했습니다.
- 만든 앱과 대화는 공유하거나 게시하지 않았습니다. 실제 상담 접수와는 연결하지 않았습니다.
