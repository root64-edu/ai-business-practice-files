# 영수증 정리와 장부 반영 검증

교재용 가상 영수증 텍스트 20개, 품목 68행을 사용했습니다. 실제 영수증 이미지의 인식 성능을 측정한 실험이 아닙니다.

최초 AI 표는 정답표와 66/68행(97.1%), 영수증 단위 18/20장(90.0%)이 완전히 일치했습니다. R13의 가려진 품목과 R14의 물음표 수량은 사람이 확인할 값으로 남았습니다. 별도 확인표로 A4 용지와 수량 1을 확인했습니다. R14의 null은 요청한 물음표 형식과 달라 수정했습니다.

AI의 추가 설명에서 R13 합계를 15,300원이라고 한 것은 틀렸으며 실제 품목 합계는 15,400원입니다. R11의 인쇄 합계 30,000원과 품목 합계 29,000원의 차이는 원자료에 의도적으로 넣은 검수 항목입니다.

R17·R18은 같은 거래입니다. 자료번호를 제외한 거래 내용으로 비교하고 R18의 3행을 제외했습니다. 최종 장부는 65행, 463,100원입니다. 날짜 검사 결과 65행 모두 2026년 3~5월 범위 안입니다.

Apps Script에서 확인 행 추출, 금액·날짜 검사, 장부 반영, 메뉴 추가를 실제 실행했습니다. 초기화 없이 다시 실행하면 130행이 되므로 같은 자료를 재실행할 때는 연습용 결과 영역을 비웁니다. 실제 누적 장부에 이 초기화 절차를 적용하지 않습니다.

P2_AppsScript_실행결과.xlsx는 실행 후 Google 시트를 내려받은 파일입니다. XLSX에는 Apps Script가 포함되지 않으므로 p2_student_code.gs를 별도로 제공합니다.
